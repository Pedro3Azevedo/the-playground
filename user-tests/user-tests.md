# User Tests

## Phase 1

Users will be testing how important are the features and define priorities. 
For this, users will be navigating through an interactive prototype, by following tasks.
After the tasks, users will make a Feature Prioritization Exercise with card sorting into: Essencial, Important, Nice to Have, Not Needed.

Scenarios

    1 - Verifica os jogos existentes num campo proximo
    2 - Cria uma equipa nova
    3 - Ve quantos jogadores vao estar em campo no dia 20 de janeiro as 17horas
    4 - Ve os jogadores no ultimo jogo que ganhaste
    5 - Cria um novo jogo
    6 - Pesquisa campos no mapa
    7 - Ve o teu proximo Jogo
    8 - Ve a tabela de classificacao de um campo
